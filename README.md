# MultiCallculator — мультикалькулятор объектов

## О проекте

MultiCallculator — внутренний веб-инструмент Global Cleaning и 112 Cleaning для предварительной оценки клининговых и абразивоструйных работ на объекте. Менеджер выбирает методологию, задаёт параметры объекта и сразу получает ориентировочную стоимость, срок выполнения, детализацию расчёта и готовый текст для клиента.

Текущая версия — одностраничное статическое приложение: интерфейс, стили и расчётная логика находятся в `index.html`, внешние библиотеки, сборка и backend не используются. Каждый калькулятор открыт в отдельной вкладке и изолирован во встроенном `iframe` через `srcdoc`.

> Результаты являются предварительной оценкой. Финальную стоимость необходимо фиксировать после осмотра объекта и, когда это применимо, пробного участка.

## Текущие возможности

### Общие

- три калькулятора в едином интерфейсе с переключением по вкладкам;
- автоматический перерасчёт при изменении исходных данных;
- вывод итоговой суммы, эффективной ставки, ориентировочного срока и детализации составляющих;
- предупреждения о диапазоне ставки и экономике расчёта;
- генерация текста коммерческого предложения и копирование его в буфер обмена;
- адаптивная двухколоночная компоновка, которая перестраивается в одну колонку на узких экранах.

### Калькуляторы

| Вкладка | Что учитывает | Что выводит |
|---|---|---|
| **Пожар** | Площадь и базовую ставку, высоту, требования заказчика, отделку, доступ, срочность и режим работ; демонтаж и вывоз, лестницы, скрытые полости, лючки и резерв; норму выработки, состав бригады и стоимость чел-дня | Стоимость и эффективную ставку, срок и чел-дни, производственную себестоимость, валовую маржу, детализацию блоков и предупреждение по экономике |
| **Металл** | Тип и местоположение объекта; известную площадь, расчёт по размерам или количеству изделий; состав работ, состояние поверхности, геометрию и доступ; параметры действующей модели очистки | Диапазон ставки и общей стоимости только абразивоструйной очистки, расчётную площадь, выработку, смены и срок; отдельное предупреждение о выбранных работах, которые требуют оценки и не входят в стоимость |
| **АСТ кирпич_фасад** | Площадь и ставку, высоту, тип кирпича, загрязнение, доступ, сегмент и требования заказчика; организационные коэффициенты; укрепляющий состав, гидрофобизацию и расшивку швов; резерв, норму и бригаду | Стоимость, эффективную ставку, срок, разбивку основных и дополнительных работ и предупреждение по ставке |


Калькулятор металла на первом этапе переработки структурирован по объекту, объёму, составу работ, поверхности, геометрии и доступу. Новые описательные параметры не получают коэффициентов и не меняют цену. Действующая стоимость по-прежнему рассчитывается только для абразивоструйной очистки; sweep blasting, механическая подготовка, грунтование, окраска, укрывка, сбор абразива и утилизация явно отмечаются как требующие отдельной оценки.

Калькулятор фасада дополнительно позволяет сохранить краткую запись расчёта в `localStorage` текущего браузера, показать список сохранений и удалить отдельную запись. Эти данные не синхронизируются между браузерами или устройствами и могут исчезнуть при очистке данных сайта. Расчёты пожара и металла не сохраняются.

## Запуск

### Требования

Достаточно современного браузера. Устанавливать зависимости и выполнять сборку не нужно.

### Рекомендуемый способ: локальный HTTP-сервер

Из корня репозитория выполните:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000). Для остановки сервера нажмите `Ctrl+C` в терминале.

Локальный сервер рекомендуется вместо открытия файла напрямую: Clipboard API надёжно работает в безопасном контексте (`localhost` или HTTPS), а доступность буфера обмена и локального хранилища для страницы, открытой по `file://`, зависит от браузера и его настроек.

Если команда `python3` недоступна, но установлен Node.js, можно запустить любой статический сервер, например:

```bash
npx serve .
```

Этот вариант может потребовать загрузки пакета из сети. Используйте адрес, который напечатает `serve`.

### Открытие без сервера

Можно открыть `index.html` двойным щелчком или перетащить файл в окно браузера. Сами расчёты будут доступны, но копирование текста и сохранение фасадных расчётов могут быть ограничены политиками браузера.

## Как пользоваться

1. Откройте приложение и выберите вкладку **Пожар**, **Металл** или **АСТ кирпич_фасад**.
2. Заполните параметры объекта. Результат обновляется автоматически.
3. Проверьте детализацию, срок, предупреждение и текст для клиента в правой части калькулятора.
4. Нажмите **Скопировать текст для клиента**. При запросе браузера разрешите доступ к буферу обмена.
5. На вкладке фасада при необходимости нажмите **Сохранить расчёт**; сохранение останется только в текущем браузере.

`spec.md` описывает целевую серверную модель, а не уже реализованную архитектуру. В текущем приложении нет базы данных, API, авторизации, ролей, рабочих пространств, клиентов, объектов и версионирования расчётов. Единственное постоянное хранение — локальные записи калькулятора фасада в браузере.

## Технические особенности

- стек: HTML5, CSS и нативный JavaScript;
- приложение не выполняет сетевые запросы и не требует конфигурации окружения;
- все вычисления выполняются на стороне браузера;
- данные введённых форм не отправляются на сервер;
- копирование использует Clipboard API (`navigator.clipboard`);
- фасадные сохранения используют ключ `facadeCalcs` в `localStorage`;
- автоматизированные тесты и отдельный процесс сборки пока отсутствуют.
