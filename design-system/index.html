Найденные расхождения → единый эталон

  • Несколько радиусов используются одновременно. Закрепляем их по роли: 10px поля, 12px action-кнопки, 16px карточки, 999px tabs/pills.
  • В светлых фонах используются близкие значения. Закрепляем: #f4f6f8 для страницы, #f9fafb для служебных блоков, #eef2ff для pill.
  • Основной тёмный цвет интерфейса — #111827. Новые почти одинаковые тёмные оттенки не добавляем.
  • Шрифт остаётся Arial, sans-serif; новый шрифт без отдельного решения не вводим.
